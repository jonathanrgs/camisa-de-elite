# Camisa de Elite Monorepo

Este repositório contém o frontend (React + Vite + Tailwind) e backend (Node + Express + Prisma) do projeto.

## Comandos

- Instalar dependências:
```
npm install
```
- Iniciar todos os serviços em dev:
```
npm run dev
```
- Iniciar apenas frontend:
```
npm run dev:front
```
- Iniciar apenas backend:
```
npm run dev:back
```

## Estrutura
- apps/frontend
- apps/backend
- docs/
